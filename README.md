과제 요건: Github Pages 배포.

## 로컬 미리보기
그냥 `index.html` 더블클릭으로 브라우저에서 열어도 됩니다.

## Github Pages 배포
1. 이 폴더 전체를 새 GitHub 저장소에 업로드
2. GitHub → Settings → Pages → Build and deployment: **Deploy from a branch**
3. Branch: `main` / Folder: `/ (root)` 선택 → Save
4. 잠시 후 `https://<username>.github.io` 또는 `https://<username>.github.io/<repo>` 로 접속

## 커스터마이징 포인트
- `assets/profile.png` 본인 사진으로 교체
- `index.html`의 이름/문구/링크 수정
- `script.js`의 프로젝트 목록 갱신
- 연락처 이메일을 실제 메일로 교체
